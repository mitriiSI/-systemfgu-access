# Midiary

Полный проект расписания: сервер Flask, веб-интерфейс, Telegram и MAX, загрузка фотографий и PDF, учебные материалы, домашние задания, дедлайны и личные баллы по истории.

В репозитории находится версия `2026.10.09.7`. Учётные записи, базы данных, пользовательские файлы, ключи и настройки рабочего сервера в публикацию не входят.

## Запуск сервера

Нужны Docker с Compose и домен, направленный на ваш сервер. Порты 80 и 443 должны быть доступны.

```sh
git clone https://github.com/mitriiSI/-systemfgu-access.git midiary
cd midiary
cp .env.example .env
python3 -c "import secrets; print(secrets.token_urlsafe(48))"
```

Запишите полученную строку в `SESSION_SECRET` в файле `.env`. Укажите свой Telegram ID в `PRIMARY_ADMIN_ID`, домен в `SITE_DOMAIN` и адрес вида `https://ваш-домен` в `PUBLIC_URL`. Для входа и уведомлений через мессенджеры заполните соответствующие токены ботов.

```sh
docker compose up -d --build
docker compose logs --tail=100 app
```

Caddy обслуживает HTTPS, Nginx раздаёт статические файлы и ограничивает частоту запросов, Flask обрабатывает API. Постоянные данные создаются в `data/`. Зависимости Python устанавливаются из `requirements.txt`; копия установленных библиотек с рабочего сервера не требуется.

Один токен бота должен обслуживаться одним запущенным экземпляром приложения. Для тестового сервера используйте отдельные токены.

## Возможности

- Выбор факультета и группы, личные подгруппы.
- Распознавание загруженных расписаний и проверка результата перед сохранением.
- Редактирование времени, аудитории и преподавателя занятия.
- Учебные материалы, домашние задания, личные записи и дедлайны.
- Вход через Telegram и MAX, напоминания и уведомления сайта.
- Личные баллы по истории: одно числовое поле и общая сумма.
- Статистика пользователей и инструменты администратора.
- Светлая и тёмная темы, свайпы календаря и анимации элементов.

Каталоги групп находятся в `catalog/`. Служебные настройки и разрешения конкретных пользователей хранятся в базе данных и на новом сервере настраиваются заново.

## Структура

```text
app.py, run.py, config.py    — приложение и настройки
routes/                     — HTTP API и вход
services/                   — расписания, распознавание, права и уведомления
bot/                        — обработчики Telegram и MAX
static/, templates/         — интерфейс и локальные браузерные библиотеки
catalog/                    — каталоги факультетов и групп
tests/                      — проверки серверного поведения
Dockerfile, compose.yaml    — сборка и запуск
edge/, Caddyfile             — HTTP и HTTPS
.env.example                — шаблон настроек без ключей
```

## Проверки

Серверные проверки используют отдельную временную базу и запускаются без токенов ботов:

```sh
docker build -t midiary-test .
docker run --rm --network=none \
  --tmpfs /tmp:rw,nosuid,nodev,size=512m \
  -v "$PWD/tests:/app/tests:ro" \
  -e PYTHON_DOTENV_DISABLED=1 \
  -e SESSION_SECRET=isolated-midiary-tests-secret-at-least-32-characters \
  -e PRIMARY_ADMIN_ID=100000001 \
  -e DATA_DIR=/tmp/midiary-tests \
  midiary-test python -m unittest discover -s /app/tests -v
```

При подготовке версии на рабочем сервере прошли 223 серверных теста и 9 проверок интерфейса в браузере.

## Демонстрация интерфейса

Ранее опубликованная самостоятельная демонстрация сохранена в `index.html` и `assets/`. Она использует вымышленные данные. Инструкция для неё находится в [docs/demo.md](docs/demo.md).

```sh
python3 -m http.server 5173 --bind 127.0.0.1
```

Откройте `http://localhost:5173`. Полный сервер запускается через Docker Compose по инструкции выше.

## Сторонние компоненты

В `static/vendor/` находятся локальные компоненты для документов и Liquid Glass. Их сведения об авторах и лицензиях сохранены рядом с файлами. Для пересборки Liquid Glass смотрите `scripts/build-liquid-glass.mjs` и `frontend/README.md`.

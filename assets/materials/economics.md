# Спрос и предложение

Демонстрационный конспект.

Спрос описывает количество товара, которое покупатели готовы приобрести при заданной цене.
Предложение описывает количество товара, которое продавцы готовы предложить при заданной цене.

Вопросы для подготовки:

1. Как изменение цены влияет на объём спроса?
2. Какие факторы могут сдвинуть кривую предложения?
3. Как определяется равновесная цена?

# Источники расписания

Для факультетов с синхронизацией в интерфейсе есть ссылка «Источник расписания». Для ФИЯР и ФГП используется самостоятельная загрузка файлов. Дневник показывает только данные о занятиях в собственном оформлении; страницы сайтов и оформление таблиц не копируются.

- ФГУ: [«Мой ФГУ»](https://my.spa.msu.ru/), действующий API расписания групп.
- Геофак: [таблица географического факультета](https://docs.google.com/spreadsheets/d/1UlXc5_d5vOx74Pq0O3hCdWD6nRRBuWNZFhBu0ozEsmU/edit), опубликованный XLSX. Листы соответствуют курсам, столбцы — группам и направлениям. Первая учебная неделя считается верхней; далее верхняя и нижняя недели чередуются. Пары без отметки недели показываются в обе недели.
- Истфак: [система расписания исторического факультета](http://ccs2.hist.msu.ru/index.php?mnu=143). Список групп выбирается по уровню, направлению и году набора; занятия загружаются по месяцам. Сайт хранит этот выбор в сессии, поэтому запросы выполняются последовательно в одной сессии.

Герб истфака взят со [страницы официальной символики факультета](https://www.hist.msu.ru/about/media/brand/). Оригинальное изображение показано без изменения цветов на белом фоне, как указано факультетом.

Добавление ссылки на источник не заменяет разрешение правообладателя, если оно требуется для конкретного способа использования данных. Перед публичным распространением можно согласовать автоматическое получение и показ расписания с факультетами.


ФИЯР и ФГП работают без получения данных с внешних сайтов. Каталоги групп сохранены один раз в `catalog/ffl-groups.json` и `catalog/fgp-groups.json`; сведения о получении — в соседних файлах `*-catalogue-origin.json`. ФИЯР: актуальные документы осени 2026/2027 со страницы http://www.ffl.msu.ru/study/timetable/timetable.php, выгруженные 07.10.2026. Документ второго курса культурологии на момент выгрузки был пустым: отсутствующую группу можно указать самостоятельно. ФГП: предоставленный пользователем файл «1-Фгп.pdf», 44 группы Факультета глобальных процессов. В каталогах нет занятий, расписания появляются только после загрузки пользователем. Обновления каталогов по сети и фоновой синхронизации для этих факультетов нет.
